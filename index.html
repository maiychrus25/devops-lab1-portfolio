01 / CODE

Website tĩnh

HTML và CSS tạo một trang giới thiệu responsive, mở được trực tiếp trên trình duyệt.

02 / AUTOMATE

GitHub Actions

Mỗi lần cập nhật nhánh main, workflow kiểm tra file và chạy bước triển khai.

03 / DELIVER

GitHub Pages

Workflow sẽ đóng gói trang thành Pages artifact và triển khai sau khi GitHub Pages được bật cho repository.

Vòng đời DevOps

Plan → Code → Build → Test → Deploy → Monitor

Workflow chạy khi có commit mới trên main. GitHub Actions kiểm tra index.html, tải artifact Pages lên và triển khai. Trạng thái thực tế được xem trong tab Actions của repository.
